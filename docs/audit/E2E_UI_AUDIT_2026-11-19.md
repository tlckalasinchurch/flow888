# End-to-End UI click-through & connection audit (2026-11-19)

**Build:** `e320bd2` (+ two fixes below). **Method:** Playwright Chromium headless against the
real `Flow8LanHub` server (the static assets from `flow8/web_ui` served exactly as in
`python main.py`), at 1366x768 and iPad 1024x768. MIDI endpoints were fake (in-process) so the
connection lifecycle could be driven deterministically; outbound/inbound were observed through
the same `Flow8Service` boundary the real app uses.

## Result

- **101 checks, 101 passed, 0 failed.**
- Uncaught JS exceptions: **0** (after the fix below).
- Unexpected HTTP failures (4xx/5xx outside the by-design 403/409/503 guards): **0**.
- Page-level horizontal/vertical overflow at both viewports: **0**.

## Defects found and fixed

1. **`mergePlanChanges is not defined`** (FlowAi "REVIEW ALL"). A regression from the earlier
   console rewrite: the button referenced a helper that was never defined, so clicking "Review
   all as one plan" threw and the plan panel never opened. Fixed by restoring the helper in
   `flow8/web_ui/app.js`.
2. **Stage view cards overlapped at 768 px.** `grid-auto-rows: minmax(0, 1fr)` squeezed two
   rows into the top pane while cards kept `min-height: 230px`, so the second row's rotary
   knob SVG overflowed onto the first row's MUTE button and intercepted its pointer events.
   Fixed: rows grow naturally (`max-content`), cards clip their own overflow, and a compact
   block sizes the knobs down on short viewports.
